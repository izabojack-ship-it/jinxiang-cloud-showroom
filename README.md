# 金享車業雲端展間

15 站 360° 虛擬實境環景導覽（依工廠動線）。

## 公開網址

https://izabojack-ship-it.github.io/jinxiang-cloud-showroom/

## 導覽順序

1. 工廠大門  
2. 一樓品保實驗室 → 一樓量測區  
3. 一樓研發模具室  
4. 一樓走道空間 → 一樓生產線-前 → 一樓生產線-中 → 一樓生產線-後  
5. 一樓出貨走道區  
6. 一樓噴塗區  
7. 一樓保稅倉庫區  
8. 二樓門口 → 二樓走廊 → 二樓設計課 → 二樓業務部  

## 上線內容

公開倉庫僅包含瀏覽器用檔案：

- `index.html`、`css/`、`js/`
- `media/panoramas/`、`media/thumbs/`、`media/stations.json`

原始拍攝與拼接腳本不會上傳。

## 本機預覽

```powershell
cd "D:\金享車業雲端展間"
python -m http.server 7979
```

開啟 http://localhost:7979
